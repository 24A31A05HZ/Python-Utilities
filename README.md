# Python Utilities

A collection of small and useful Python programs built to practice Python programming and create practical utilities.

This repository contains beginner-friendly Python projects covering **automation, randomization, file handling, QR codes, data processing, and other useful tasks**.

## 📂 Projects

| # | Project                 | Description                                     | Concepts Used                  |
| - | ----------------------- | ----------------------------------------------- | ------------------------------ |
| 1 | 🔐 Password Generator   | Generates strong random passwords               | `random`, strings              |
| 2 | 📱 QR Code Generator    | Generates QR codes from text or URLs            | `qrcode`                       |
| 3 | 📁 File Organizer       | Organizes files into folders based on file type | `os`, `pathlib`, file handling |
| 4 | 🧮 Calculator           | Performs basic mathematical operations          | Functions, operators           |
| 5 | 🎯 Number Guessing Game | Guess a randomly generated number               | `random`, loops, conditions    |
| 6 | 📄 PDF Merger           | Combines multiple PDF files into one            | File handling, libraries       |
| 7 | 🖼️ Image Resizer       | Resizes images using Python                     | `Pillow`                       |
| 8 | 📊 CSV Analyzer         | Reads and analyzes CSV data                     | `csv`, data processing         |

> More utilities will be added as I learn and build new Python programs.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/24A31A05HZ/python-utilities.git
```

### 2. Open the repository

```bash
cd python-utilities
```

### 3. Run a program

For example:

```bash
python PasswordGenerator/password_generator.py
```

Some projects may require additional libraries.

Install them using:

```bash
pip install -r requirements.txt
```
